# 部署指南

目标：代码在 GitHub 上，网站有一个公网链接，能直接发给别人、能用手机打开。

平台用 **Vercel**（Next.js 官方推荐，个人项目免费，额度足够）。

推荐走 **GitHub 接入** 的方式：部署一次之后，以后每次改动推上去，网站自动更新。

```
本地代码  →  GitHub  →  Vercel  →  公网网址
                              ↑
                        自动构建，不用再管
```

---

## 第 1 步：上传到 GitHub

1. **双击 `上传到GitHub.command`**

2. 按提示去 <https://github.com/settings/tokens/new> 申请一个 Token：
   - Note 随便填，比如 `pet-link`
   - Expiration 选 `90 days`
   - 勾选 **`repo`**（只要这一个）
   - 点底部的 `Generate token`
   - 复制 `ghp_` 开头的那串（**只显示一次**）

3. 回到终端，粘贴用户名和 Token（Token 输入时不会显示字符，是正常的）

4. 上传完成后会自动打开仓库页面：<https://github.com/Hanny-0303/Pet-Link>

Token 会顺手存进 macOS 钥匙串，以后 push 不用再输。

---

## 第 2 步：Vercel 导入

1. 打开 <https://vercel.com/new>
2. 用 **GitHub 账号**登录
3. 列表里找到 `Pet-Link`，点 **Import**
4. **什么都不用改**——Vercel 会自动识别出这是 Next.js 项目
5. 点 **Deploy**，等 1–3 分钟

完成后会得到类似 `https://pet-link-xxxx.vercel.app` 的网址。

把这个网址填进 `README.md` 顶部的 `[在线演示](#)` 里，然后再推一次就显示出来了。

---

## 之后怎么更新

改完代码，让 AI 帮你：

```bash
git add -A && git commit -m "改了什么" && git push
```

Vercel 检测到新提交会自动重新部署，1–2 分钟后网址上就是新版本。

也可以用 `部署.command`（命令行直连 Vercel），但它和 GitHub 接入是两套，**别混用**，否则会出现两个项目。

## 常见问题

### 链接打开很慢，或者打不开

`*.vercel.app` 在中国大陆访问不稳定，这是 Vercel 的已知问题，不是代码问题。

| 办法 | 说明 |
|---|---|
| 换网络试试 | 手机 4G/5G 常常比家里宽带快 |
| 绑自己的域名 | Vercel 项目 Settings → Domains，国内会好一些 |
| 换 Cloudflare Pages | 免费，国内通常更稳，但要重新配置一次 |
| 先这样 | 面试演示用手机热点，基本没问题 |

### 部署失败

Vercel 的 Deploy 页面会显示构建日志。本地 `npm run build` 能通过，线上一般也能过。

最常见的坑是 `package.json` 和 `package-lock.json` 不同步——本项目已经处理好了。

### 想改网址里的 `pet-link`

Vercel 项目 → Settings → Project Name → 改名。改完域名变成 `新名字.vercel.app`，旧的失效。

### 部署完发现页面是旧的

浏览器缓存。Mac 上 `Cmd + Shift + R` 强制刷新。

## 附：不用 GitHub 的直连方式

如果只是想快速看效果，也可以跳过 GitHub：

**双击 `部署.command`** → 登录 Vercel → 自动部署。

缺点是代码不在 GitHub 上，也没有自动更新。**只适合临时看效果。**

手动命令行版：

```bash
npx vercel login
npx vercel deploy --prod --yes --project liuliu-pet --create-if-missing
```

## 部署前检查清单

- [x] `npm run build` 本地通过
- [x] 静态资源（26 张宠物照片）在 `public/img/`，不依赖外链
- [x] `.vercelignore` 排除了 `node_modules`、`.next`、`.tooling`
- [x] `package-lock.json` 与 `package.json` 同步（Vercel 用 `npm ci`）
- [ ] 部署后用手机、以及一个没登录过的浏览器打开，确认没有缓存造成的假象
